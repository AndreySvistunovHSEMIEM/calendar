# Орбита — космический календарь на Go

Локальное веб-приложение для планирования событий. Go-сервер отвечает за API,
проверку данных, хранение и экспорт. Интерфейс написан на HTML, CSS и JavaScript
и встроен в исполняемый файл через `go:embed`. Сторонних Go-пакетов нет.

![Интерфейс Орбиты](docs/preview.png)

## Запуск

Нужны **Go 1.22 или новее** и современный браузер.

```bash
git clone https://github.com/AndreySvistunovHSEMIEM/calendar.git
cd calendar
go run .
```

Открыть **http://127.0.0.1:8080**. Остановка сервера — `Ctrl+C`.

В этой рабочей папке можно запустить `./start.sh`. Он находит Go в `PATH` или
в локальном кеше `~/.cache/space-calendar/go/bin/go`. На компьютере разработки
Go загружен с официального сайта, архив проверен по SHA-256; глобальные настройки
системы не менялись. Сам кеш не входит в исходники проекта.

Локальная папка разработки называется `space-calendar`; клонированная с GitHub
папка по умолчанию называется `calendar`.

Чтобы заполнить **новое** хранилище примерами:

```bash
./start.sh -demo
```

На macOS можно дважды нажать `start.command`: он запускает этот же вариант.
Демонстрационные события расположены относительно даты первого запуска и
помечены в описании. Это примеры планов, а не расписание астрономических явлений.
Повторный запуск с `-demo` не добавляет события в уже существующее хранилище.
Для отдельной демонстрации: `go run . -demo -data data/demo.json -addr 127.0.0.1:8081`.

## Возможности

- Месячный календарь, недельный обзор, список за месяц и список всех событий.
- Переход между месяцами, мини-календарь, кнопка «Сегодня».
- Создание, редактирование, удаление и восстановление последнего удалённого
  события кнопкой «Отменить» в уведомлении, пока страница не перезагружена.
- События на весь день или на заданное время в пределах одного дня.
- Название, описание, место, категория и отметка о завершении.
- Четыре категории: работа, личное, учёба, космос. Фильтры управляют календарём,
  списком и боковой панелью. Счётчики категорий показывают общее число событий.
- Поиск по названию, описанию и месту среди всех дат с учётом фильтров.
- События выбранного дня и три ближайших незавершённых плана после этого дня.
- Экспорт всех событий в `.ics` независимо от активных фильтров.
- Адаптивная вёрстка для компьютера и телефона, русскоязычный интерфейс.
- Космическое оформление: звёзды, планета с кольцами, мягкие лиловые акценты.
  Графика создана средствами CSS/SVG, внешние ресурсы не загружаются.

Клик по дню выбирает дату; двойной клик по свободному месту дня открывает
создание события. Клик по событию открывает редактирование.
`N` (или `Т` в русской раскладке) — новое событие, `/` — поиск,
`Escape` — закрыть диалог. Когда кнопка даты в основном календаре в фокусе,
стрелки перемещают выбор на день или неделю. Формы имеют подписи; состояние
операции и ошибки показываются в интерфейсе.

## Данные и границы приложения

По умолчанию данные находятся в `data/events.json`. Изменения сохраняются
сразу: временный файл записывается и синхронизируется, затем заменяет основной.
Ошибка записи не изменяет календарь в памяти. Повреждённый или несовместимый
файл не перезаписывается; сервер сообщает об ошибке и прекращает запуск.
Для резервной копии можно скопировать JSON при остановленном сервере.

Приложение рассчитано на **одного пользователя и один процесс сервера на файл**.
Параллельные HTTP-запросы внутри процесса защищены мьютексом. Не запускайте два
процесса с одним файлом. Несколько открытых вкладок не обновляются автоматически;
после изменений из другой вкладки следует перезагрузить страницу. При одновременном
редактировании одного события сохраняется последний полученный сервером вариант.

Даты поддерживаются от 1900 до 2100 года. Неделя начинается с понедельника.
Время относится к местным часам пользователя; оно не переводится в UTC.
В экспорте используется «плавающее» время: импортирующий календарь интерпретирует
его в своей зоне. У события на весь день `DTEND` указывает следующий день.
Нет повторяющихся событий, учётных записей, облачной синхронизации, импорта ICS
или фоновых уведомлений. Состояние фильтров и вида не сохраняется после обновления.

Сервер по умолчанию доступен только на `127.0.0.1`. Приложение не предназначено
для публикации без дополнительной аутентификации и HTTPS. Проверяются размер
JSON, неизвестные поля, содержимое события и Origin изменяющих запросов.
Фронтенд экранирует пользовательский текст; CSP запрещает внешние скрипты.

## Структура

```text
main.go             запуск, встроенный фронтенд, завершение по сигналу
store.go            модель Event, валидация, JSON-хранилище

store_test.go        сохранение, границы дат, конкуренция, ошибки записи

docs/                архитектура и результаты проверки
start.sh             запуск из терминала
start.command        запуск на macOS
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/events` | Все события, по дате и времени |
| POST | `/api/events` | Создать событие, ответ 201 |
| PUT | `/api/events/{id}` | Заменить событие, ответ 200 |
| DELETE | `/api/events/{id}` | Удалить событие, ответ 204 |
| GET | `/api/export` | Скачать `orbita.ics` |

Пример тела POST (`Content-Type: application/json`):

```json
{
  "title": "Изучение Go",
  "date": "2026-10-08",
  "start": "14:00",
  "end": "15:30",
  "allDay": false,
  "category": "study",
  "description": "Практика с net/http",
  "location": "Дома",
  "completed": false
}
```

ID создаётся сервером. Для PUT передаётся полное событие.
Для `allDay: true` время очищается сервером. Ошибки возвращаются как
`{"error":"Сообщение"}`: 400 — JSON, 403 — чужой Origin, 404 — событие не найдено,
413 — размер запроса, 415 — тип содержимого, 422 — поля, 500 — запись на диск.

## Проверка и сборка

```bash
go test -race ./...
go vet ./...
go build -o bin/orbita .
./bin/orbita
```

Для `-race` нужен установленный C-компилятор. Обычный `go test ./...` не требует
его. Исполняемый файл содержит весь фронтенд, его можно запускать отдельно от
исходников; путь к JSON задаётся относительно текущей рабочей папки или абсолютно.

## Исходные учебные материалы

Пользователь предоставил ссылки на кейсовые задания, лабораторные работы,
методические материалы для начинающих и продвинутых, а также презентации.
8 октября 2026 года доступная проверка ссылок Яндекс открыла страницу входа;
содержимое материалов прочитать не удалось. Поэтому соответствие конкретным
пунктам учебного задания **пока не подтверждено**. Реализация опирается на прямое
требование пользователя: календарь на Go с космической тематикой. После получения
доступных файлов требования можно сверить с готовым приложением.
