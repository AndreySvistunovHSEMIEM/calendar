# Проверка приложения

Дата: 8 октября 2026 года. Среда: macOS arm64, Go 1.27.1,
встроенный браузер Codex.

## Автоматические проверки

- `go test -race ./...` — пройдено, гонки не обнаружены.
- `go vet ./...` — пройдено.
- `go build -o bin/orbita .` — исполняемый файл собран.
- `bash -n start.sh start.command` — пройдено.

Девять тестовых функций проверяют HTTP-цикл создания/изменения/удаления,
экспорт, встроенные файлы интерфейса, неправильный JSON, чужой Origin,
ограничение размера запроса, високосные даты, несуществующие даты,
время окончания, длину русского текста и категории. Проверяется повторное
открытие JSON-хранилища, 20 параллельных записей, отказ записи без изменения
памяти и отказ запуска с повреждённым JSON или повторяющимися ID.

В экспорте проверяются границы полного дня, локальное время, экранирование
разделителей и переносов, а также перенос строк по 75 байт без разрыва UTF-8.

## Проверки через интерфейс

1. Календарь загружен с семью явно демонстрационными событиями.
2. Создано временное событие «QA · Проверка орбиты».
3. Время окончания до начала отвергнуто с понятной ошибкой; после исправления
   событие сохранено. Строка с `<script>` и `&` показана как обычный текст.
4. После обновления страницы событие прочитано из хранилища.
5. Название изменено, событие переведено в режим «Весь день».
6. Поиск по изменённому названию нашёл событие; отключение категории «Космос»
   скрыло его; включение категории вернуло результат.
7. Событие отмечено как завершённое, удалено через подтверждение и восстановлено
   кнопкой «Отменить». Затем временное событие удалено после проверки.
8. Проверены недельный вид, переход на следующую неделю, список событий и
   возвращение к сегодняшнему дню.
9. В консоли браузера при этих операциях ошибок и предупреждений не было.
10. Проверена вёрстка при ширине 390 и 320 пикселей: горизонтального переполнения
    документа не обнаружено. Временное изменение размера браузера сброшено.
11. Сервер остановлен и снова запущен из собранного исполняемого файла.
    Контрольная сумма JSON не изменилась; сохранены все семь демо-событий.

Скриншоты: `preview.png` — полный экран календаря в обычном размере окна,
`mobile.png` — мобильная вёрстка шириной 390 пикселей.

## Ограничения проверки

Файлы учебной документации по ссылкам Яндекс были недоступны без авторизации.
Соответствие их конкретным критериям не установлено. Импорт `.ics` в сторонние
календари и другие браузерные движки не проверялись. Скриншот мобильной вёрстки
получен изменением ширины браузера, а не запуском на физическом телефоне.
