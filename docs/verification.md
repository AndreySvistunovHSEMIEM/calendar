# Проверка Орбиты по учебным требованиям

Дата: 8 октября 2026 года. Среда: macOS arm64, Go 1.27.1 и Docker Desktop.
Проверены Go-код, интерфейс в браузере и работающий PostgreSQL/RabbitMQ-стенд.

## Автоматические проверки

`go test -race ./...`, `go vet ./...`, сборка Docker-образа и проверка синтаксиса
shell-скриптов прошли. Go-тесты проверяют HTTP-цикл, JWT и сессии, владельца,
высокосные даты, время, JSON-валидацию, экспорт, 20 одновременных файловых записей,
ошибку диска без изменения памяти и отказ чтения повреждённого файла.

Отдельный тест graceful shutdown удерживает активный HTTP-запрос, посылает
остановку и подтверждает, что сервер возвращается только после полного ответа.
Usecase-тест подтверждает вызов репозитория для `/test` и отклонение неправильного
события до обращения к хранилищу.

PostgreSQL-интеграционный тест запущен в настоящем контейнере и отдельной БД
`orbita_tests`. Он проверяет чужого владельца, атомарную запись события и outbox,
защиту новой ревизии от старого статуса, идемпотентное повторное применение,
захват сообщений с арендой и повторный захват после истечения аренды. Обычный
`go test` без настроенной БД этот внешний тест пропускает; здесь он выполнен отдельно.

## Работающий стенд

Собраны и запущены API, PostgreSQL, RabbitMQ, worker, Prometheus и Grafana.
Дополнительно запущен профиль `load`. `/test` вернул точную строку `Hello!`,
`/readyz` подтвердил подключение к хранилищу, `/dbtest` сохранил строку в PostgreSQL.

`scripts/smoke.py` прошёл на реальном API: регистрация двух пользователей,
отказ при неправильном пароле, 401 без входа, отсутствие чужих событий в списке
и экспорте, 404 при чужом изменении/удалении, создание и изменение своих событий,
`pending → ready` через обе очереди RabbitMQ и экспорт ICS. После пересоздания
API сохранённое событие и сессия остались доступны; выход отозвал JWT-сессию.

Prometheus подтвердил доступность `orbita-api`, `orbita-worker`, `orbita-loadgen`.
API Grafana подтвердил автоматически установленный дашборд `orbita-overview`
с восемью панелями. Метрики опубликованных, обработанных и готовых заданий
присутствовали в Prometheus.

## Нагрузочный прогон

Сервис нагрузки зарегистрировал 20 разных пользователей и за 30 секунд выполнил
599 HTTP-операций создания, просмотра и удаления. Ошибок — 0, частота —
19,96 запроса/с, медиана — 2,03 мс, p95 — 3,73 мс. Полные численные результаты
с UTC-временем прогона сохранены в `load-report.json`.

Это ограниченный учебный прогон на локальном компьютере. Значения измеряют
HTTP-ответ и не включают время обработки задания в очереди. Предельная нагрузка
и распределённый эксплуатационный стенд не исследовались.

## Браузер

Проверены регистрация нового аккаунта, пустой личный календарь, создание события
на весь день, сохранение сессии и события после обновления страницы, удаление,
выход, отказ с неправильным паролем и вход в демо-аккаунт с семью событиями.
В первой версии и при обновлении проверены месячный и недельный виды, список,
поиск, фильтры, редактирование, отметка о завершении и отмена удаления.

[Календарь](preview.png) и [мобильная версия](mobile.png) показывают демо-данные,
[экран входа](login.png) показывает форму авторизации. Мобильная проверка использует изменение ширины браузера;
запуск на физическом телефоне не выполнялся.
